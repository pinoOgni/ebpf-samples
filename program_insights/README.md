# eBPF Program Insights

This folder contains a simple eBPF XDP example.

The code is used as a companion example for the following article:

**[eBPF Program Insights](https://pinoogni.github.io/articles/ebpf-program-insights/)**

The same article was later published on the **eBPFChirp** blog:

**[Reading Between the Bytes: Inspecting Compiled eBPF with bpftool, readelf & llvm-objdump](https://ebpfchirp.substack.com/p/reading-between-the-bytes-inspecting)**
